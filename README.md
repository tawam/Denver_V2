# Denver MMA 120 — página mestra

## Estrutura
- `index.html` — página do produto.
- `styles.css` — identidade visual e responsividade.
- `script.js` — animações leves e galeria de vistas.
- `data/product.json` — conteúdo estruturado do produto.
- `assets/icons/` — ícones SVG fornecidos.
- `assets/images/` — imagens otimizadas para web.
- `assets/brand/` — logos Denver.
- `ASSET_CATALOG.md` — catálogo dos assets.
- `SOURCE_ORDER.md` — ordem editorial aplicada.
